# نظام تسجيل الطلاب وتوزيعهم على مجموعات (MongoDB)

## التشغيل
1. افتح ملف `.env` واستبدل `<db_password>` بباسورد مستخدم قاعدة بيانات Atlas.
2. من MongoDB Atlas > Network Access: أضف IP جهازك (أو 0.0.0.0/0 للاختبار).
3. في الـ Terminal داخل المجلد:
   ```
   npm install
   npm test
   npm start
   ```
4. افتح http://localhost:3000

## الصفحات
- `/` التسجيل
- `/find.html` بحث الطالب عن مجموعته
- `/admin.html` لوحة المشرف (اسم مستخدم + باسورد من ملف .env)

## لوحة المشرف
- نقل طالب من مجموعة لأخرى (📌 = منقول يدوياً، وفيه زر "إلغاء النقل")
- تحميل Excel (ورقة "المجموعات": كل مجموعة جدول، وورقة "كل الطلاب")
- إضافة روابط الواتساب، وحذف طالب

## ملاحظة أمان
ملف `.env` فيه كلمات السر: لا ترفعه على GitHub ولا تشاركه.
